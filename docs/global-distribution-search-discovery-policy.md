# LifeToLife Search & Discovery Optimization Policy

Canonical policy date: 2026-08-16 KST

This policy is a mandatory second pass after platform-native transformation and before publishing or manual hand-off.

Canonical flow:

`source content -> platform-native transformation -> search/discovery optimization -> platform-ready package -> publish/hand-off -> verification -> measurement`

## 1. Core rule

LifeToLife does not optimize for keyword count. It optimizes for **matching a real audience intent while remaining natural and useful on the destination platform**.

For NUNCHI, the initial intent cluster is:

- primary: `Korean social cues`, `Korean culture`, `learn Korean`
- contextual: `living in Korea`, `Korean communication`, `Korean etiquette`
- product/concept: `nunchi`, `nunchi meaning`, `눈치`
- scenario phrase where relevant: `괜찮아요`

These are positioning/search-intent terms, **not claimed search-volume rankings**. Performance data must determine later revisions.

Do not stuff all terms into every package. Select the smallest natural subset that matches the specific post.

## 2. Search/discovery gate

Before a job is marked `ready + publish`, verify:

1. the audience query or discovery topic is explicit;
2. the main phrase appears naturally near the beginning where the platform benefits from it;
3. title/caption/body/on-screen language agree on the same topic;
4. tags/hashtags/labels are relevant and platform-native rather than generic reach bait;
5. media platforms include the topic in the **actual visible/spoken content**, not metadata alone;
6. links and CTAs do not turn the post into a thin link drop;
7. the asset is original or materially original where recommendation systems reward originality;
8. the package has a destination-specific UTM when an outbound link is appropriate;
9. no channel is published merely to increase channel count.

## 3. Platform rules

### Facebook — Auto Publish

Discovery emphasis: Feed/Reels recommendation plus Facebook search/AI discovery.

- Lead with a human question/problem containing the topic naturally.
- Prefer `Korean social cues`, `Korean communication`, or `Korean culture` in the first paragraph when relevant.
- Keep the post self-contained before the outbound link.
- Do not rely on hashtags as the discovery strategy.
- Prefer original LifeToLife media and substantive original framing; do not recycle low-value copies.
- Measure reach, engagement, link clicks and downstream play sessions.

### Instagram — Auto Publish, media required

Discovery emphasis: Reels/Explore/search/recommendations.

- Put the core query in the opening caption and in on-screen or spoken media text.
- Use original vertical media rather than placeholder/recycled media.
- House rule: use a small set of highly relevant hashtags rather than a generic hashtag block.
- Example topic set for NUNCHI: `Korean social cues`, `learn Korean`, `Korean culture`, `nunchi`.
- Optimize cover text for immediate topic recognition.
- Measure reach from non-followers, watch/retention, saves/shares and profile/link actions.

### Threads — Auto Publish

Discovery emphasis: keyword search, topic discovery and topic-sensitive recommendations.

- Put the topic phrase in natural prose, not a hashtag wall.
- Use one clear conversational idea per post.
- Prefer language that can participate in a live/niche conversation: a question, observation or tension.
- Use topic tagging only when the publishing surface supports it reliably; do not fake topic tags with unrelated hashtags.
- Measure views, replies, reposts, profile actions and outbound traffic where a link is used.

### Bluesky — Auto Publish

Discovery emphasis: full-text search, exact phrases, hashtags and custom feeds.

- Keep the main search phrase in the text.
- Use 1–2 precise searchable hashtags when useful.
- Stay comfortably inside the post limit; do not sacrifice the core phrase for filler.
- Prefer terms likely to be queried exactly, e.g. `Korean social cues`, `#KoreanCulture`, `#LearnKorean`.
- Measure reposts/likes/replies and UTM traffic.

### Blogger — Auto Publish

Discovery emphasis: Google/Bing indexing and persistent long-tail search.

- Put the primary phrase near the beginning of the title.
- Keep SEO-oriented titles concise; house target is under 60 characters where possible.
- Use natural keyword variants in the body and meaningful H2/H3 structure where supported.
- Add relevant Blogger labels; do not create large generic label sets.
- Ensure the article is public/indexable.
- Each article must answer a real query rather than merely announce a product.
- Measure indexed impressions/clicks when Search Console data is available plus UTM traffic.

### WordPress.com — Auto Publish

Discovery emphasis: search engines, WordPress Reader/site taxonomy and AI-search citation readiness.

- Primary keyword near the beginning of the title; house target roughly 50–60 characters.
- Use a descriptive slug.
- Write a unique, accurate search description/excerpt; house target roughly 150–160 characters.
- Use natural keywords in visible content and descriptive headings.
- Use a small, consistent taxonomy. For NUNCHI launch content, prefer about five specific tags rather than broad tag inflation.
- A campaign marked for public distribution must be **published and indexable**, not left as a draft.
- Measure search impressions/clicks, Reader/site traffic and downstream UTM sessions.

### Tumblr — Auto Publish

Discovery emphasis: text search and global tag search.

- Put searchable wording in both visible text and the dedicated Tumblr tag field.
- Front-load the most specific/relevant tags.
- Initial NUNCHI tag set should remain compact: `Korean culture`, `learn Korean`, `Korean social cues`, `nunchi`, `living in Korea`, `Korean language`, `Korean etiquette`.
- Publish as an original post rather than a reblog when discovery is the goal.
- Measure notes, reblogs, search/tag discovery where visible and UTM traffic.

### YouTube — Auto Publish, media required

Discovery emphasis: query relevance + engagement/quality + recommendations.

- Put the exact viewer problem near the front of the title.
- Repeat the topic naturally in the first description sentences.
- The video itself must visibly/speak the same topic; metadata cannot compensate for unrelated footage.
- Thumbnail/first seconds must deliver the same promise as the title.
- Do not spend effort on large tag lists. Use tags mainly for useful spelling variants if needed.
- Measure search traffic, impressions/CTR, audience retention, watch time and downstream actions.

### X — Assisted Manual

Discovery emphasis: keyword/hashtag search and conversation relevance.

- Use the core phrase in ordinary text.
- Use no more than two relevant hashtags as a LifeToLife operating rule, matching X's own best-practice guidance.
- Avoid near-duplicate repeated posts.
- Prefer a useful observation or question over a naked outbound link.
- Measure impressions, engagements and UTM traffic.

### TikTok — Assisted Manual, media required

Discovery emphasis: search-query match, recommendation signals and watch behavior.

- Put the target phrase in on-screen text, spoken/audio content where natural, and caption.
- Use precise topic hashtags; do not use generic `#fyp` as the optimization strategy.
- The first seconds must immediately demonstrate the query/problem.
- Optimize for completion and rewatch without withholding the core answer dishonestly.
- Measure search/discovery traffic if surfaced, completion, average watch time, shares/saves and profile actions.

### Reddit — Assisted Manual

Discovery emphasis: title/body search plus subreddit relevance and discussion quality.

- Put the precise topic in the title naturally.
- Make the body useful without requiring the outbound click.
- Use community language and invite a specific substantive response.
- Avoid repetitive cross-subreddit promotional copies.
- For NUNCHI, useful searchable concepts include `Korean social cues`, `learning Korean`, `living in Korea`, `Korean culture`, and the concrete phrase/problem being discussed.
- Measure comments, votes, outbound traffic and qualitative feedback.

### Snapchat Spotlight — Assisted Manual, media required

Discovery emphasis: Spotlight content classification, keywords/metadata and predicted watch/engagement behavior.

- Put the topic visibly in the Snap and in the description/keywords where the upload surface permits it.
- Use relevant hashtags/#Topics rather than broad trend bait.
- Design for immediate comprehension and completion.
- Keep this channel manual until Public Profile API allowlisting is formally confirmed.
- Measure completion/watch behavior, favorites/shares and profile actions where available.

## 4. Pending channels

### Pinterest — pending Trial approval

If approved:

- Put the main query near the front of the Pin title.
- Use a descriptive, keyword-natural Pin description and destination URL.
- Use relevant topics/board naming instead of generic tags.
- Favor evergreen visual search intent such as `Korean social cues`, `Korean culture guide`, and scenario-specific queries.
- Do not activate until the existing Trial review approves.

### Hatena Blog — pending blog-opening review

If approved:

- Treat Hatena as a Japanese-web discovery surface, not an English duplicate blog.
- Adapt title and terminology to Japanese search intent before publishing.
- Use Hatena categories that describe the article accurately.
- Do not activate until the existing blog-opening review approves.

## 5. Measurement loop

Each campaign should record at minimum:

- campaign ID and canonical source;
- per-channel search/discovery phrase;
- published URL/ID;
- UTM source when applicable;
- reach/impressions where available;
- search/referral traffic;
- engagement appropriate to the channel;
- downstream NUNCHI play/session action where measurable;
- qualitative feedback;
- next revision decision.

A platform rule may be changed when actual performance contradicts this starting policy. Do not preserve a weak format for consistency.

## 6. Implementation status as of 2026-08-16

- Tumblr adapter already accepts dedicated `tumblr_tags`.
- Current Blogger adapter publishes title/body but does not yet forward Blogger `labels`; adapter enhancement is required for full label optimization.
- Current WordPress.com adapter hardcodes `draft`; public campaign search visibility requires an adapter change so an explicitly approved publish job can create a public post and pass SEO/taxonomy metadata.
- Instagram/YouTube require real media assets; do not insert placeholder media merely to satisfy channel count.
- TikTok/Snapchat search packages should be prepared with the media asset even though the final upload remains manual.

Until adapter enhancements are deployed, do not claim full technical search optimization for Blogger labels or WordPress public indexing.
